# 店铺类型与平台门槛（只覆盖 JIBIN 实际在做的）

## 零、这份表的边界

只讲 JIBIN 实际在运营的七种组合：

| 地区 | 平台 | 店铺类型 |
|---|---|---|
| 俄罗斯 | OZON | 跨境店（FBO / FBS） |
| 俄罗斯 | Wildberries | 跨境店（FBO / FBS） |
| 俄罗斯及独联体 | **速卖通 CIS（独立主体）** | CIS 站店铺 |
| 全球（欧美为主） | **速卖通全球店** | POP 店 |
| 全球（欧美为主） | **速卖通全球店** | 海外托管店（海托） |
| 欧美 | Temu | Y2 店铺类型 |
| 欧美及东南亚 | TikTok Shop | 跨境店（平台物流 / 自发货） |

**不在这张表里的平台，不给判断。** 统一回答：这个市场我不做，建议找实际做过的卖家问。

> **最重要的一条**：速卖通 CIS 和速卖通全球店**不是一个主体**。
> CIS 属于俄罗斯及独联体，全球店是另一套。主体不同、后台不同、类目和规则都不能互相套用。

## 一、先分清"平台 × 店铺类型"

同一个平台，不同店铺类型的门槛完全不同，这是小白最容易糊的地方。

| 平台 | 店铺类型 | 一句话人话 | 谁适合 |
|---|---|---|---|
| OZON | 跨境店 | 用中国执照开店，货从中国发；FBO 送平台仓，FBS 自己发 | 想先测俄罗斯市场 |
| Wildberries | 跨境店 | 同上，俄语区另一个大流量池 | 俄罗斯线的第二选择 |
| 速卖通 CIS | CIS 站店铺 | 俄罗斯及独联体的独立主体，和全球店不是同一个账号、同一套规则 | 只做俄语区 |
| 速卖通全球店 | POP 店 | 卖家自营：自己定价、自己运营、自己发货 | 有一定运营能力 |
| 速卖通全球店 | 海外托管店 | 备货到海外仓，平台负责流量和部分履约，你让出一部分控制权 | 有资金能压货 |
| Temu | Y2 店铺类型 | Temu 的非全托管模式，价格与供货要求跟全托管不同 | 有稳定供货能力 |
| TikTok Shop | 跨境店 | 内容带流量，靠短视频和直播成交；不是传统货架逻辑 | 能持续产出内容的人 |

> 「海外托管店」和「Y2」两行的具体口径，以 JIBIN 实际运营规则为准，发布前请本人核对一遍。

## 二、门槛五道（七种组合都要过）

| 顺序 | 门槛 | 过不了会怎样 |
|---|---|---|
| 1 | 主体资质（营业执照：企业或个体户） | 开不了店 |
| 2 | 类目准入（品类准不准入、要不要资质） | 上不了架 |
| 3 | 资金门槛（保证金 + 备货 + 广告） | 撑不到验证就断了 |
| 4 | 语言与后台（看不看得懂、能不能处理客服） | 进去了也做不动 |
| 5 | 合规与认证（如 EAC、CE） | 货到了也上不了架 |

**一道不过，后面不用谈。** 按顺序讲，不要跳着讲。

## 三、每种组合最容易卡在哪（只讲实际遇到过的）

| 组合 | 最容易卡的地方 |
|---|---|
| OZON 跨境店 | 俄语后台；部分类目要本地认证；FBO 入库有预约和验收要求 |
| Wildberries 跨境店 | 俄语与本土化内容；认证；FBS 时效要求严 |
| 速卖通 CIS | 和全球店不是一个主体：账号、后台、类目都不通用，照搬全球店经验会踩坑 |
| 速卖通全球店 POP | 类目佣金与价格竞争；广告投放能力 |
| 速卖通全球店 海外托管 | 备货压资金，选错品会压在海外仓 |
| Temu Y2 | 平台对价格和供货稳定度的要求 |
| TikTok Shop 跨境店 | 内容制作能力是硬门槛，不会拍不会播就做不动；类目部分要资质；达人合作与内容合规要求 |

具体驳回与处罚口径以后台当期为准。

## 四、发货模式别名（只列这四家）

| 平台 | 平台仓（先送仓） | 自发货（自己发） |
|---|---|---|
| OZON | FBO | FBS（另有 realFBS：卖家自配物流） |

> 速卖通 CIS 的发货口径按 CIS 站后台为准，不要套用全球店。

## 五、常见驳回和卡住原因（材料类，通用）

- 执照信息与店铺填写信息不一致
- 营业执照经营范围不含所售类目
- 身份证明与执照法人不是同一人
- 类目需要认证，但没上传文件
- 收款账户与开店主体不一致

被驳回时先看驳回原因那句原文，再逐项对材料，不要重复提交同一份材料。

## 六、遇到范围外的平台怎么说

固定话术，不放宽：

> 这个市场我不做，不给判断。你要做的话，找实际在这个平台跑过的卖家问。

不评价、不比较、不给替代建议。

---

## 七、回答纪律三条

1. **先讲店铺类型，再讲门槛**。他不知道自己能开哪种店，讲门槛是空的。
2. **每个术语后面跟一句人话**。说"FBS"必须补一句"就是自己存货自己发"。
3. **不报数字**。保证金、佣金、时效一律"以后台当期为定"。
4. **速卖通 CIS 和全球店分开讲**。用户说"速卖通"时先问一句：是俄罗斯独联体的 CIS，还是全球店。

---

## 八、四个常见误判（回答时顺手纠正）

| 误判 | 实际情况 |
|---|---|
| 平台大 = 好做 | 平台大 = 竞争大、规则严、广告贵 |
| 某个平台"红利期" | 红利期是事后总结，事前无法判断；能判断的只有自己的条件够不够 |
| 别人能做我也能做 | 你看不到他的货源、资金、团队 |
| 换个平台就能出单 | 出不了单通常是品和成本的问题，不是平台的问题 |

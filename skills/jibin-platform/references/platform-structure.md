# 平台结构特征对照

> 只做结构判断。保证金、佣金、时效、类目细则**全部以后台当期为准**，这里不写数字。

## 一、五个平台的稳定结构

| 平台 | 要不要备货入仓 | 靠不靠广告买量 | 靠不靠内容 | 定价权在谁 | 主要门槛 |
|---|---|---|---|---|---|
| 亚马逊 | 要（平台仓模式） | 高度依赖 | 不靠 | 平台 + 竞争 | 资质、品牌、广告预算、认证 |
| OZON | 可选：入仓或不入仓 | 中等 | 不靠 | 卖家为主 | 俄语、本地认证、物流线路 |
| 速卖通 | 可不入仓，可小批量 | 中等 | 不靠 | 卖家为主 | 类目佣金、价格竞争 |
| TikTok Shop | 不强制入仓 | 中等 | **强依赖** | 内容决定流量 | 持续产出内容的能力 |
| Temu | 全托管需备货 | 平台负责流量 | 不靠 | **平台掌握** | 平台定价、要备货、利润薄（本质是供货模式，不是零售卖家角色） |

## 二、按人匹配（排除法）

| 他的情况 | 排除 |
|---|---|
| 资金 5 千以下 | 亚马逊（压货 + 广告）、Temu 全托管（要备货） |
| 不会拍不会剪、也不想学 | TikTok Shop |
| 外语完全不行 | 后台和客服全外语的平台 |
| 没有稳定货源 | 价格由平台掌控的类型做不了，没有成本优势 |
| 想小成本先验证一个品 | 优先考虑可不入仓、可小批量的平台 |
| 有工厂 | 成本优势明显，但身份仍是零售卖家，不做供货商；不要因为手里有厂就去接批发单 |

## 三、"先确认的三件事"怎么写

每家都从这三类里挑，必须写清去后台哪个页面看：

1. **类目要求**：你要卖的品类，准不准入、要不要资质或认证
2. **费用结构**：保证金、佣金比例、有没有月租（看后台费率页，不听别人说）
3. **发货与时效**：能用哪种发货模式、时效要求是什么、超时怎么处罚

## 四、被问到"到底哪个平台最好"时

不回答排名，改回答这句话：

> 没有最好的平台，只有你现在这个条件能过的平台。你现在卡在〔具体那项〕，换平台也一样卡。

## 五、四个常见误判（写进回答里提醒他）

| 误判 | 实际情况 |
|---|---|
| 平台大 = 好做 | 平台大 = 竞争大，规则严，广告贵 |
| 某个平台"红利期" | 红利期是事后总结，事前无法判断；能判断的只有自己的条件够不够 |
| 别人能做我也能做 | 你看不到他的货源、资金、团队 |
| 换个平台就能出单 | 出不了单通常是品和成本的问题，不是平台的问题 |

# 产品判断规则

## 一、运费关算式（照抄给用户）

```
体积重(kg) = 长(cm) × 宽(cm) × 高(cm) ÷ 6000
计费重(kg) = max(实重, 体积重)
单件运费 ≈ 计费重 × 每公斤价 + 挂号费（如渠道有）
```

分母 6000 是空运常见值，**必须让用户向货代确认**，不同渠道分母不同。

### 三条硬判据

| 判据 | 结论 |
|---|---|
| 客单价 < 计费重运费 × 3 | 不成立 |
| 计费重 ÷ 实重 > 2 | 抛货，只适合高客单或轻小件 |
| 计费重 > 2kg 且客单价低 | 强烈不建议做跨境小包 |

### 算例（讲给他看）

包装 30×20×15cm，实重 0.4kg，售价计划 60 元：

```
体积重 = 30×20×15 ÷ 6000 = 1.5kg
计费重 = max(0.4, 1.5) = 1.5kg
```

按 1.5kg 计费，运费很容易超过 60 元的三分之一，这个品在低价带不成立。

**同一个品，如果改成可压缩包装、体积降到 20×15×10，体积重 0.5kg**，运费立刻降下来。这就是为什么要先量外箱再下单。

## 二、合规清单（命中即要先判）

| 关键词 | 风险 | 处理 |
|---|---|---|
| 品牌 logo、仿牌、动漫形象 | 侵权，罚没 + 封店 | 不建议做，除非有授权 |
| 内置电池、配套电池、充电宝 | 渠道限运 | 先确认渠道能收 |
| 液体、膏体、粉末、气雾 | 渠道限运 | 先确认渠道能收 |
| 强磁、刀具、激光 | 渠道限运 | 先确认渠道能收 |
| 餐厨、水杯、儿童餐具 | 食品接触，要材质认证 | 没认证不发 |
| 儿童玩具、婴儿用品 | 安全认证 | 没认证不发 |
| 电器、灯具 | 能效/安全认证 | 没认证不发 |

## 三、市场结构特征（只判方向，不报数据）

| 市场 | 适合什么品 | 主要代价 |
|---|---|---|
| 俄罗斯（OZON 等） | 轻小件、日用、价格敏感型 | 需处理俄语与本地认证，冬季长、旺季窗口早 |
| 欧美（速卖通、TikTok Shop 等） | 客单价较高、品质型 | 认证严、退货率高、广告投放成本 |
| 东南亚 | 低价快消、轻小件 | 客单价低，运费占比高，竞争激烈 |
| 中东、拉美 | 新兴品类 | 物流周期长，支付与售后复杂 |

## 四、被问到"这个品能不能爆"时

不改口搞预测，改说这句：

> 爆不爆我不知道，也没人知道。我能判断的是这个品在运费和合规上过不过得去。过不去的品，再爆也跟你没关系。

## 五、四个常见误判

| 误判 | 实际情况 |
|---|---|
| 国内卖得好 → 国外也能卖 | 需求结构不同，季节和习惯都不一样 |
| 体积小 = 运费便宜 | 看的是体积重，不是看着小 |
| 运费卖家承担，不影响定价 | 运费直接决定你的保本售价 |
| 先上架再看能不能卖 | 上架前不算清成本，卖一单亏一单 |

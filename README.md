# JIBIN出海 · jibin-skill

JIBIN 的中文 AI Skill：**跨境新手 7 天动作清单**。

装到支持 Skills 的 Agent（豆包、Claude Code、Codex、WorkBuddy 等）后，在对话里说一句话，就能拿到一张「接下来 7 天每天做什么」的清单。

不教概念、不给资料、不讲趋势。只给动作顺序。

作者：JIBIN出海 · 跨境出海 8 年

## 包含哪些技能

| 技能 | 用途 | 状态 |
|---|---|---|
| `jibin-decide` | 入局自检：现在该不该动手，敢劝退，给最多亏多少、多久见分晓 | 可用（入口技能） |
| `jibin-platform` | 这个平台的门槛和你能开哪种店：先讲店铺类型，再讲门槛五道 | 可用 |
| `jibin-match` | 这个产品能不能做、卖到哪：运费关、合规关、需求关，带算式 | 可用 |
| `jibin-7days` | 新手 7 天 / 14 天动作清单，先定品还是先开店 | 可用 |
| `jibin-logistics` | 发货方案判断：选渠道、算成本构成、敏感货判定、OZON 的 FBO/FBS 怎么选 | 可用（先支持 OZON） |

### 不用记名字，说人话就行

技能内部名字是英文（格式要求），但**你不需要记住任何一个**。装上以后直接说你的情况：

| 你说的话 | 它会用哪个 |
|---|---|
| 我能不能做跨境、要投多少钱、现在晚不晚 | 入局自检 |
| 这个平台好不好做、做速卖通还是 OZON | 平台好不好做 |
| 我这个产品能不能卖、能卖到哪 | 产品能不能做 |
| 货怎么发、运费多少、敏感货能不能寄 | 发货怎么走 |
| 第一步干什么、接下来按什么顺序做 | 新手动作清单 |

拿不准就随便问，`jibin` 这个总入口会判断该用哪一个。

俄罗斯及独联体：**OZON、Wildberries、速卖通 CIS**
全球（欧美为主）：**速卖通全球店（POP、海外托管）、Temu Y2、TikTok Shop**

不在这份名单里的平台不给判断，统一回答"这个市场我不做，建议找实际做过的卖家问"。

## 它解决什么

新手最常见的问题不是「不懂」，是「不知道今天该干什么」，然后一上手就去注册店铺、交保证金、囤货，钱花完了还没验证过任何一个品。

这个 Skill 的作用就是**替他把顺序摆正**：

定品 → 核价（运费 + 佣金 + 退货）→ 算清第一单成本 → 才注册店铺

## 怎么用

装好后直接说人话，不用记命令：

```text
我想做俄罗斯市场，卖厨房小工具，手里有 1 万块，每天能弄两三个小时，
完全没开始，也没有货源，我该先干什么
```

它会先补齐缺的信息，然后给出：

- 一句话结论（很多时候是「先别开店」）
- 7 天或 14 天清单，每天一个任务，标注耗时和要不要花钱
- 先别做的三件事
- 你最大的风险

信息没给全也可以，它会一次问一个。

## 安装

### 方式一：对豆包说一句话（最简单，手机上就能装）

打开豆包，在对话框里发这一句：

```text
安装 jibin-chuhai 的 jibin-skill
```

装好之后，直接在对话里说人话就能用，不需要电脑，不需要终端。

### 方式二：命令行（给会用终端的人）

```bash
npx -y skills add jibin-chuhai/jibin-skill -g --all
```

### 方式三：手动拷贝

1. 下载本仓库
2. 把 `skills/jibin-7days` 整个文件夹复制到你的 Agent 的 skills 目录
3. 重启 Agent，在对话里说「用 jibin-7days 帮我排个清单」
